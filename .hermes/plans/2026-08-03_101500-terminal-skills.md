# Memperkaya Skill Terminal Hermes — Rencana Implementasi

> **Untuk Hermes:** implement task-by-task. Semua skill dibuat dengan
> `skill_manage(action='create')` memakai format resmi *Agent Skills*
> (`SKILL.md` + YAML frontmatter), di bawah `~/.hermes/skills/<kategori>/<nama>/`.

**Goal:** Menambah ~5–10 skill terminal baru yang powerful + rekomendasi skill lain
yang belum ada, mengikuti standar format Agent Skills dari agentskills.io, tanpa
duplikasi dengan skill yang sudah ada di sistem.

**Architecture:** Riset menyimpulkan `agentskills.io` adalah **situs dokumentasi
spesifikasi** (spec format, best-practice, quickstart) — **bukan** katalog skill
siap-download. Jadi pendekatan yang benar = **menulis skill sendiri** sesuai standar
itu, bukan mengimpor. Skill ditulis berbahasa Indonesia (selaras dengan skill
`clean-terminal-output` milik user).

**Tech Stack:** `SKILL.md` (frontmatter + markdown), skrip pendukung bash/python di
`scripts/`, tools CLI standar (jq, rg, awk, sed, ss, lsof, tmux, htop, git, curl, dsb).

---

## Konteks

- Hermes memuat skill dari `~/.hermes/skills/` (file `SKILL.md`, frontmatter
  `name` + `description`).
- Sudah ada: `clean-terminal-output` (format output), `systematic-debugging`,
  `terminal` built-in, `github-*`, `mlops/*`, `productivity/*`, `software-development/*`.
- **Belum ada** skill yang mengemas utilitas terminal tajam: parsing JSON, diag
  jaringan, manajemen proses, tmux, transformasi teks/log.

## Keputusan Kunci

`agentskills.io` = referensi STANDAR cara menulis skill yang baik
(baca: `https://agentskills.io/specification` + `/skill-creation/best-practices`),
bukan source untuk mengimpor skill instan. Kita ikuti best-practice-nya saat menulis.

## Task 1 — `terminal-json`

**Objective:** Parsing/filter/transform JSON di terminal memakai `jq` (dan yq)
dengan contoh nyata serta peringatan error.

**Files:**
- Create: `~/.hermes/skills/software-development/terminal-json/SKILL.md`

**Frontmatter (template semua skill):**
```yaml
---
name: terminal-json
description: Use when parsing/filtering/transforming JSON from CLI with jq/yq. Terminal JSON utilities.
version: 1.0.0
license: MIT
metadata:
  hermes:
    tags: [terminal, json, jq, cli]
---
```

**Isi body:** akses `.key`, `.[]`, `select(.x>1)`, `map`, `group_by`, `--raw-output`,
pipe antar command. Peringatan: input bukan JSON → error `jq`; cek `command -v jq`.

**Verifikasi:** `echo '{"a":1,"b":2}' | jq '.a'` -> `1`.

## Task 2 — skill `terminal-network`

**Objective:** cepat diagnosa koneksi/port/latency memakai `ss`, `lsof`, `curl -sv`,
`nc`, `ping`, `traceroute`, `dig`, `ip`.

**Files:**
- Create: `~/.hermes/skills/software-development/terminal-network/SKILL.md`

**Isi:** skenario umum (port listening? service up? DNS resolve? latency) + contoh
command + output + verifikasi. Catatan: `lsof` butuh izin utk socket milik user lain.

## Task 3 — `terminal-processes`

**Objective:** daftar/perbaiki proses & background job: `ps`, `kill`, `pkill`,
`top`/`htop`, `jobs`/`fg`/`bg`, `&`, `disown`, `nohup`, `wait`, `$?`, `time`.

**Files:**
- Create: `~/.hermes/skills/software-development/terminal-processes/SKILL.md`

**Isi:** SOP aman (validasi `ps` sebelum `kill`), contoh manajemen long-running.

---

## Task 4 — `terminal-text`

**Objective:** olah log/file besar: `awk`, `sed`, `rg`, `cut`, `sort`, `uniq -c`,
`head/tail`, `wc`, `xargs`, pipeline.

**Files:**
- Create: `~/.hermes/skills/software-development/terminal-text/SKILL.md`

**Isi:** pola umum (ekstrak kolom, count uniq, filter baris, dedup, sampling). Contoh parse access-log.

---

## Task 5 — `tmux`

**Objective:** sesi tmux multipanel + detach untuk job panjang.

**Files:**
- Create: `~/.hermes/skills/software-development/tmux/SKILL.md`

**Isi:** `tmux new -s <nama>`, prefix `Ctrl-b`, `detach`, `attach -t`, windows & panes,
resize, `kill-session`. Verifikasi: `tmux ls`.
