## Risiko & Tradeoffs

- **Risiko: dependency opsional** — kalau psutil/jinja2/dsb belum terinstall, tool tidak akan terdaftar (bukan crash). Solusi: gunakan `soft.register` + fallback error message.
- **Tradeoff: SQL read-only** — block-write regex bisa false-positive. Mitigasi: hanya block keyword di akhir statement (`CREATE TABLE` vs `SELECT * FROM create_table`).
