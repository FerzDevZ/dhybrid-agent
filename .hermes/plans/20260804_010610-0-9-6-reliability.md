# Rilis 0.9.6 — Reliability Power-up (retry + redis persistence + MIME media)

> **For Hermes:** gunakan subagent-driven-development skill untuk mengerjakan plan ini task-by-task. TDD ketat.

**Goal:** Tingkatkan reliability & observability: retry yang cerdas, state persistence cross-session via redis, serta MIME detection audio/video yang kuat. Elevasi agent dari stable 0.9.5 ke produksi-capable.

**Architecture:**
- Tambah layer retry (`tenacity`) di provider HTTP (Anthropic/OpenAICompat).
- Tambah layer persistence (`redis`) di SessionStore — fallback SQLite.
- Perpanjang `_is_image_bytes` → `_is_media_bytes` — audio/video detect.

**Tech Stack:** Python 3.12, tenacity (retry), redis (persistence), python-magic (MIME).
