# dhybrid-agent — Implementation Plan

> **Untuk Hermes:** gunakan skill `subagent-driven-development` untuk mengimplementasikan plan ini task-by-task.

**Goal:** Membangun CLI coding agent bernama **dhybrid-agent** — powerful untuk tugas coding, super hemat token, berarsitektur *hybrid* (routing model kecil/murah untuk kerja mekanis + model besar untuk penalaran berat), dengan filosofi *own-your-data* (local-first).

**Architecture:** 3 lapis — (1) *LLM layer*: client multi-provider terpadu — satu adaptor OpenAI-compatible (mencakup OpenAI, OpenRouter, Groq, DeepSeek, Gemini) + adaptor native Anthropic dengan prompt caching; (2) *Efficiency core*: token budget, context compaction, prompt/semantic cache, lazy policies; (3) *Agent runtime*: loop ReAct, registry tool, hybrid router, session store SQLite, UI REPL. Semua state lokal (SQLite + file), tanpa server.

**Tech Stack:** Python 3.12 (tersedia di mesin), stdlib-first (`argparse`, `sqlite3`, `dataclasses`), dependensi minimal: `httpx` (streaming SSE) + `pyyaml` (config). Dev: `pytest`. TIDAK pakai framework agent berat — agent loop ditulis sendiri supaya hemat token dan mudah dikendalikan.

**Prinsip utama:** *You can't optimize what you don't measure* → semua keputusan hemat token didasari metrik yang dicatat per sesi.

## 2. Strategi Hemat Token (Core Differentiator)

12 teknik, diurutkan dari dampak terbesar:

1. **Lazy policies (Ponytail)** — system prompt berisi aturan: *jangan tulis kode yang tidak diminta, jangan refactor tanpa alasan, cari helper yang sudah ada dulu, edit minimal (hunk terkecil)*. Ini menghemat puluhan persen token output.
2. **Context compaction** — setelah N pesan / melewati soft budget, pesan lama diringkas oleh model murah (bukan dihapus), pesan terakhir K pesan dipertahankan verbatim. Gaya claude-mem.
3. **Prompt caching** — kirim `cache_control` (Anthropic) / manfaatkan prefix caching (OpenAI/Gemini) untuk system prompt + tool definitions yang tidak berubah antar turn. Bisa potong biaya input 50-90%.
4. **Hybrid router** — tugas mekanis (grep, format, jalankan test, edit kecil) dirutekan ke model kecil/murah cloud (mis. `gpt-4o-mini` / `claude-haiku` / `gemini-flash` / `deepseek-chat`); tugas penalaran (arsitektur, debugging kompleks) ke model besar (`claude-sonnet` / `gpt-4o` / `gemini-pro`). Router = classifier murah + aturan heuristik + cache klasifikasi.
5. **Tool output discipline** — `read_file` dengan line range, `head/tail` default, dedup output berulang, cap panjang output per tool, diff-based edit (tidak pernah menulis ulang file penuh).
6. **Token budget** — budget lunak (soft → pemicu compact) dan keras (hard → stop/force-compact) per sesi, dihitung dari estimasi + `usage` API.
7. **System prompt minimal & compiled-once** — template system prompt disusun sekali per sesi (bukan per turn), tool definitions ringkas.
8. **Structured/JSON tool calls** — format tool-call JSON ringkas + schema minimal, bukan XML verbose.
9. **Early stop** — `stop` sequences, `max_tokens` per fase, hentikan loop saat model menandai selesai (bukan menunggu turn penuh).
10. **Semantic cache** — hash (model, prompt) untuk panggilan deterministik (mis. klasifikasi routing, summarization berulang); cache hasil tool yang idempotent.
11. **Session resume via ringkasan** — resume sesi lama memuat ringkasan + intent, bukan transcript penuh.
12. **Metering** — dashboard token per sesi/task: input, output, cached, estimasi biaya; statusline live. *Tanpa ini, semua di atas tidak terukur.*

Target metrik (diukur di Phase 12, bukan klaim): task coding standar (fix bug kecil, tambah fitur kecil) ≤ 40k token total; biaya turun ≥ 50% vs agent tanpa kompresi/caching pada benchmark yang sama.

from __future__ import annotations
import os
from dataclasses import dataclass, field
from pathlib import Path
import yaml

@dataclass
class ModelConfig:
    provider: str = "openai"
    model: str = "gpt-4o-mini"
    base_url: str | None = None
    api_key_env: str = "OPENAI_API_KEY"
    max_tokens: int = 4096
    temperature: float = 0.2

@dataclass
class Config:
    workspace: Path = Path.home() / ".dhybrid"
    model: ModelConfig = field(default_factory=ModelConfig)
    small_model: str | None = None
    budget: dict = field(default_factory=lambda: {"soft": 60000, "hard": 120000})
    context: dict = field(default_factory=lambda: {"keep_recent": 8, "compact_ratio": 0.5})
    tool: dict = field(default_factory=lambda: {"max_output_chars": 8000, "allowlist": []})

    @classmethod
    def load(cls, path: str | Path | None = None) -> "Config":
        path = Path(path) if path else Path("config/default.yaml")
        data = yaml.safe_load(path.read_text()) or {}
        cfg = cls()
        if "workspace" in data:
            cfg.workspace = Path(data["workspace"]).expanduser()
        if "model" in data:
            for k, v in data["model"].items():
                if k != "small_model" and hasattr(cfg.model, k):
                    setattr(cfg.model, k, v)
        cfg.small_model = data.get("model", {}).get("small_model")
        for key in ("budget", "context", "tool"):
            if key in data:
                setattr(cfg, key, data[key])
        # env override: DHYBRID_MODEL, DHYBRID_PROVIDER
        if os.environ.get("DHYBRID_MODEL"):
            cfg.model.model = os.environ["DHYBRID_MODEL"]
        if os.environ.get("DHYBRID_PROVIDER"):
            cfg.model.provider = os.environ["DHYBRID_PROVIDER"]
        return cfg
```

from __future__ import annotations
from dhybrid.config import Config, ModelConfig

class ModelRegistry:
    """Resolve preset name -> ModelConfig. Fallback: parse 'provider:model'."""
    def __init__(self, cfg: Config, presets: dict | None = None):
        self.cfg = cfg
        self.presets = presets or {}

    def resolve(self, name: str) -> ModelConfig:
        if name in self.presets:
            p = self.presets[name]
            return ModelConfig(**p)
        if ":" in name:
            provider, model = name.split(":", 1)
            return ModelConfig(provider=provider, model=model)
        raise KeyError(f"unknown model preset: {name}")
```

from pathlib import Path

def load_dotenv(path: str | Path = ".env") -> None:
    """Muat KEY=VALUE ke os.environ bila belum ada. Tidak butuh python-dotenv."""
    import os
    p = Path(path)
    if not p.exists():
        return
    for line in p.read_text().splitlines():
        line = line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        key, _, val = line.partition("=")
        key, val = key.strip(), val.strip().strip('"').strip("'")
        os.environ.setdefault(key, val)
```

**Step 1: `src/dhybrid/llm/base.py`**
```python
from __future__ import annotations
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Iterator

@dataclass
class ChatMessage:
    role: str                      # system | user | assistant | tool
    content: str
    tool_calls: list | None = None  # [{"id","name","arguments"(dict)}]
    tool_call_id: str | None = None

    def to_api(self) -> dict:
        d = {"role": self.role, "content": self.content}
        if self.tool_calls:
            d["tool_calls"] = [{
                "id": tc["id"], "type": "function",
                "function": {"name": tc["name"], "arguments": __import__("json").dumps(tc["arguments"])},
            } for tc in self.tool_calls]
        if self.tool_call_id:
            d["tool_call_id"] = self.tool_call_id
        return d

@dataclass
class Usage:
    prompt_tokens: int = 0
    completion_tokens: int = 0
    cached_tokens: int = 0
    @property
    def total(self) -> int:
        return self.prompt_tokens + self.completion_tokens

@dataclass
class ChatResponse:
    message: ChatMessage
    usage: Usage
    model: str
    cache_hit: bool = False

@dataclass
class StreamEvent:
    kind: str            # "delta" | "tool_call" | "done"
    text: str = ""
    tool_call: dict | None = None
    usage: Usage | None = None

class LLMClient(ABC):
    @abstractmethod
    def stream(self, messages: list[ChatMessage], **kw) -> Iterator[StreamEvent]: ...
    @abstractmethod
    def complete(self, messages: list[ChatMessage], **kw) -> ChatResponse: ...
```

    """Bekerja untuk OpenAI, dan API lain yang kompatibel (OpenRouter, Groq, dsb)."""
    def __init__(self, cfg: ModelConfig):
        self.cfg = cfg
        self.base_url = (cfg.base_url or "https://api.openai.com/v1").rstrip("/")
        self.api_key = os.environ.get(cfg.api_key_env, "sk-local")

    def _headers(self) -> dict:
        return {"Authorization": f"Bearer {self.api_key}", "Content-Type": "application/json"}

    def _payload(self, messages, **kw) -> dict:
        payload = {
            "model": self.cfg.model,
            "messages": [m.to_api() for m in messages],
            "max_tokens": kw.get("max_tokens", self.cfg.max_tokens),
            "temperature": kw.get("temperature", self.cfg.temperature),
            "stream": kw.get("stream", True),
        }
        if kw.get("stop"):
            payload["stop"] = kw["stop"]
        return payload

    def _post(self, payload: dict, timeout: float = 300.0) -> httpx.Response:
        last_err: Exception | None = None
        for attempt in range(3):
            try:
                return httpx.post(f"{self.base_url}/chat/completions", headers=self._headers(),
                                  json=payload, timeout=timeout)
            except httpx.HTTPError as e:
                last_err = e
                import time; time.sleep(2 ** attempt)
        raise last_err  # type: ignore[misc]

    def stream(self, messages, **kw):
        payload = self._payload(messages, **kw)
        payload["stream"] = True
        with self._post(payload) as r:
            r.raise_for_status()
            buf = ""
            for line in r.iter_lines():
                if not line or not line.startswith("data:"):
                    continue
                data = line[5:].strip()
                if data == "[DONE]":
                    break
                chunk = json.loads(data)
                delta = chunk["choices"][0].get("delta", {})
                if delta.get("content"):
                    yield StreamEvent(kind="delta", text=delta["content"])
                if delta.get("tool_calls"):
                    for tc in delta["tool_calls"]:
                        yield StreamEvent(kind="tool_call", tool_call={
                            "id": tc.get("id", ""), "name": tc["function"].get("name", ""),
                            "arguments": json.loads(tc["function"].get("arguments") or "{}"),
                        })
            yield StreamEvent(kind="done")

    def complete(self, messages, **kw) -> ChatResponse:
        payload = self._payload(messages, stream=False, **kw)
        r = self._post(payload)
        r.raise_for_status()
        data = r.json()
        msg = data["choices"][0]["message"]
        usage = data.get("usage", {})
        return ChatResponse(
            message=ChatMessage(role="assistant", content=msg.get("content") or "",
                                tool_calls=[{"id": tc["id"], "name": tc["function"]["name"],
                                             "arguments": json.loads(tc["function"].get("arguments") or "{}")}
                                            for tc in msg.get("tool_calls", [])] or None),
            usage=Usage(prompt_tokens=usage.get("prompt_tokens", 0),
                        completion_tokens=usage.get("completion_tokens", 0)),
            model=data.get("model", self.cfg.model),
        )

class AnthropicClient(LLMClient):
    """Adaptor native Anthropic /v1/messages — dengan cache_control (Task 2.4)."""
    def __init__(self, cfg: ModelConfig): self.cfg = cfg
    def stream(self, messages, **kw):
        raise NotImplementedError
    def complete(self, messages, **kw):
        raise NotImplementedError

from __future__ import annotations

def estimate_tokens(text: str) -> int:
    """Estimasi cepat: 4 char/token EN, ~1.5 char/token untuk teks campuran kode.
    Akurasi cukup untuk budget & compaction (bukan billing)."""
    if not text:
        return 0
    code_heavy = sum(1 for c in text if c in " \t\n{}();=#") / max(len(text), 1)
    ratio = 3.2 if code_heavy > 0.15 else 4.0
    return max(1, int(len(text) / ratio))

def estimate_messages(messages: list) -> int:
    return sum(estimate_tokens(m.content) for m in messages) + 4 * len(messages)
```

from __future__ import annotations
from dataclasses import dataclass, field

@dataclass
class TokenBudget:
    soft: int = 60000
    hard: int = 120000
    used: int = 0
    history: list[dict] = field(default_factory=list)

    def add(self, prompt: int, completion: int, cached: int = 0, tag: str = "") -> None:
        self.used += prompt + completion
        self.history.append({"prompt": prompt, "completion": completion,
                             "cached": cached, "tag": tag, "cum": self.used})

    @property
    def should_compact(self) -> bool:
        return self.used >= self.soft

    @property
    def exhausted(self) -> bool:
        return self.used >= self.hard

    @property
    def cache_hit_ratio(self) -> float:
        tot = sum(h["prompt"] for h in self.history)
        cac = sum(h["cached"] for h in self.history)
        return (cac / tot) if tot else 0.0
```

from __future__ import annotations
from dhybrid.llm.base import ChatMessage
from dhybrid.llm.tokens import estimate_messages

class ContextManager:
    """Menyimpan pesan, merender untuk API, dan mengompresi saat budget tercapai.
    Kompaksi: ringkas pesan TUA (di luar keep_recent) menjadi 1 pesan summary
    oleh model murah; pesan terakhir keep_recent dipertahankan verbatim."""

    def __init__(self, keep_recent: int = 8, compact_ratio: float = 0.5):
        self.keep_recent = keep_recent
        self.compact_ratio = compact_ratio
        self.messages: list[ChatMessage] = []
        self.summary: str | None = None
        self.compactions = 0

    def push(self, msg: ChatMessage) -> None:
        self.messages.append(msg)

    def estimated_tokens(self) -> int:
        head = [ChatMessage(role="system", content=f"[ringkasan sesi] {self.summary}")] if self.summary else []
        return estimate_messages(head + self.messages)

    def render(self) -> list[ChatMessage]:
        head = []
        if self.summary:
            head.append(ChatMessage(role="system", content=(
                "Berikut ringkasan percakapan SEBELUM ini. Pakai hanya bila relevan, "
                f"jangan ulangi: {self.summary}")))
        return head + self.messages

    def candidates_for_compaction(self) -> list[ChatMessage]:
        """Pesan yang boleh diringkas: semua kecuali system + keep_recent terakhir."""
        return self.messages[:-self.keep_recent] if len(self.messages) > self.keep_recent else []

    def apply_compaction(self, new_summary: str) -> None:
        """Panggil setelah summary dihasilkan: buang pesan tua, simpan summary."""
        if self.candidates_for_compaction():
            self.summary = new_summary
            self.messages = self.messages[-self.keep_recent:]
            self.compactions += 1
```

from __future__ import annotations
import hashlib
import json
import sqlite3
import time
from pathlib import Path

class PromptCache:
    """Cache respons deterministik (routing, klasifikasi, kompaksi).
    Key = hash(model + pesan terakhir yang relevan). TTL default 1 jam."""

    def __init__(self, db_path: Path | None = None, ttl: int = 3600):
        self.db_path = Path(db_path or Path.home() / ".dhybrid" / "cache.sqlite")
        self.db_path.parent.mkdir(parents=True, exist_ok=True)
        self.ttl = ttl
        self._conn = sqlite3.connect(self.db_path)
        self._conn.execute("""CREATE TABLE IF NOT EXISTS prompt_cache (
            key TEXT PRIMARY KEY, value TEXT, created REAL)""")

    @staticmethod
    def _key(model: str, messages: list[ChatMessage]) -> str:
        blob = json.dumps([m.to_api() for m in messages], sort_keys=True)
        return hashlib.sha256(f"{model}|{blob}".encode()).hexdigest()

    def get(self, model: str, messages: list[ChatMessage]) -> str | None:
        key = self._key(model, messages)
        row = self._conn.execute("SELECT value, created FROM prompt_cache WHERE key=?", (key,)).fetchone()
        if row and time.time() - row[1] < self.ttl:
            return row[0]
        return None

    def set(self, model: str, messages: list[ChatMessage], value: str) -> None:
        key = self._key(model, messages)
        self._conn.execute("INSERT OR REPLACE INTO prompt_cache VALUES (?,?,?)",
                           (key, value, time.time()))
        self._conn.commit()
```

class MessageStore:
    """Urutan pesan + helper untuk menambah hasil tool."""

    def __init__(self):
        self.items: list[ChatMessage] = []

    def add(self, role: str, content: str, **kw) -> ChatMessage:

        for m in reversed(self.items):
            if role is None or m.role == role:
                return m
        return None

    def clear(self) -> None:
        self.items.clear()

from __future__ import annotations
import json
import re

TOOL_RE = re.compile(r"```tool\n(.*?)\n```", re.DOTALL)

def parse_tool_call(text: str) -> dict | None:
    """Parsing output model berformat:
    ```tool
    {"name": "grep", "arguments": {"pattern": "x", "path": "."}}
    ```"""
    m = TOOL_RE.search(text)
    if not m:
        return None
    try:
        data = json.loads(m.group(1))
    except json.JSONDecodeError:
        return None
    if not isinstance(data, dict) or "name" not in data:
        return None
    return {"id": "gen", "name": data["name"], "arguments": data.get("arguments", {})}

def strip_tool_block(text: str) -> str:
    return TOOL_RE.sub("", text).strip()
```

from __future__ import annotations
from dataclasses import dataclass, field
from dhybrid.agent.messages import MessageStore
from dhybrid.efficiency.budget import TokenBudget
from dhybrid.efficiency.context import ContextManager
from dhybrid.llm.base import LLMClient, ChatMessage, StreamEvent
from dhybrid.tools.registry import ToolRegistry
from dhybrid.agent.parsing import parse_tool_call

@dataclass
class LoopConfig:
    max_steps: int = 20
    max_tool_output_chars: int = 8000

@dataclass
class LoopResult:
    final_text: str = ""
    steps: int = 0
    compacted: bool = False
    stopped_early: bool = False

class AgentLoop:
    def __init__(self, client: LLMClient, tools: ToolRegistry,
                 ctx: ContextManager, budget: TokenBudget,
                 cfg: LoopConfig | None = None):
        self.client = client
        self.tools = tools
        self.ctx = ctx
        self.budget = budget
        self.cfg = cfg or LoopConfig()

    def run(self, user_prompt: str, system_prompt: str) -> LoopResult:
        store = MessageStore()
        store.add("system", system_prompt)
        store.add("user", user_prompt)
        result = LoopResult()

        for step in range(self.cfg.max_steps):
            # 1) kompaksi bila budget lunak tercapai
            if self.budget.should_compact and not result.compacted:
                result.compacted = self._compact()

            # 2) panggil model (streaming, budget di-update via hooks)
            last = self._step_once(store)
            result.steps = step + 1

            # 3) early-stop: jawaban final tanpa tool-call
            if not last.tool_calls:
                result.final_text = last.content
                return result

            # 4) eksekusi tool
            for tc in last.tool_calls:
                output = self.tools.execute(tc["name"], tc.get("arguments", {}))
                output = output[: self.cfg.max_tool_output_chars]
                store.add_tool_result(tc["id"], output)
                self.ctx.push(ChatMessage(role="tool", content=output, tool_call_id=tc["id"]))

            if self.budget.exhausted:
                result.final_text = "[budget keras tercapai — sesi dihentikan]"
                return result

        result.final_text = last.content or "[max steps tercapai]"
        return result

    def _step_once(self, store: MessageStore) -> ChatMessage:
        """Satu turn model; kembalikan pesan assistant terakhir."""
        last = ChatMessage(role="assistant", content="", tool_calls=[])
        for ev in self.client.stream(self.ctx.render() + store.items[2:], ):
            if ev.kind == "delta":
                last.content += ev.text
            elif ev.kind == "tool_call":
                last.tool_calls.append(ev.tool_call)
        if not last.tool_calls:
            tc = parse_tool_call(last.content)   # fallback JSON tool block
            if tc:
                last.tool_calls = [tc]
                last.content = ""
        return last

    def _compact(self) -> bool:
        from dhybrid.efficiency.compress import compact_conversation
        cands = self.ctx.candidates_for_compaction()
        if not cands:
            return False
        summary = compact_conversation(self.client, cands)
        self.ctx.apply_compaction(summary)
        return True
```

import inspect
from dataclasses import dataclass

@dataclass
class ToolSpec:
    name: str
    description: str
    parameters: dict          # JSON-schema ringkas
    fn: callable

class ToolRegistry:
    def __init__(self, allowlist: list[str] | None = None):
        self._tools: dict[str, ToolSpec] = {}
        self.allowlist = set(allowlist or [])

    def register(self, name: str, description: str, parameters: dict, fn: callable) -> None:
        self._tools[name] = ToolSpec(name, description, parameters, fn)

    def specs(self) -> list[dict]:
        """Tool definitions ringkas untuk prompt (hemat token)."""
        return [{"name": t.name, "description": t.description, "parameters": t.parameters}
                for t in self._tools.values() if t.name in self.allowlist or not self.allowlist]

    def execute(self, name: str, arguments: dict) -> str:
        if name not in self._tools:
            return f"ERROR: tool '{name}' tidak dikenal"
        if self.allowlist and name not in self.allowlist:
            return f"ERROR: tool '{name}' tidak diizinkan (allowlist)"
        try:
            out = self._tools[name].fn(**arguments)
            return str(out)
        except TypeError as e:
            return f"ERROR argumen {name}: {e}"
        except Exception as e:
            return f"ERROR {name}: {type(e).__name__}: {e}"
```

def run_command(command: str, timeout: int = 60, max_chars: int = 8000) -> str:
    """Jalankan perintah; kembalikan stdout+stderr, di-cap."""
    try:

                              text=True, timeout=timeout)

    except subprocess.TimeoutExpired:

def read_file(path: str, offset: int = 1, limit: int = 100, max_chars: int = 8000) -> str:
    p = Path(path)
    if not p.exists():
        return f"ERROR: file tidak ada: {path}"
    lines = p.read_text(errors="replace").splitlines()
    start = max(offset - 1, 0)
    chunk = lines[start: start + limit]
    total = len(lines)
    head = f"{path} ({total} baris, menampilkan {start+1}-{start+len(chunk)})"
    body = "\n".join(f"{i+1}|{ln}" for i, ln in enumerate(chunk, start=start))
    out = f"{head}\n{body}"
    return out[:max_chars]

    return f"OK: {path} ditulis ({len(content)} chars)"

```python
from __future__ import annotations
import difflib
from pathlib import Path

def apply_patch(patch_text: str, base_dir: str = ".") -> str:
    """Terapkan patch format diff sederhana. Support satu file per panggilan.
    Format:
      --- path/relatif.py
      @@ konteks opsional
      -baris lama
      +baris baru
    Baris tanpa prefix = konteks (untuk penempatan).
    """
    lines = patch_text.splitlines()
    if not lines or not lines[0].startswith("--- "):
        return "ERROR: patch harus dimulai dengan '--- path'"
    path = lines[0][4:].strip()
    target = Path(base_dir) / path
    if not target.exists():
        return f"ERROR: target tidak ada: {path}"
    old = target.read_text().splitlines()
    removals, additions = [], []
    for ln in lines[1:]:
        if ln.startswith("@@") or not ln.strip():
            continue
        if ln.startswith("-"):
            removals.append(ln[1:])
        elif ln.startswith("+"):
            additions.append(ln[1:])
    if not removals and not additions:
        return "ERROR: patch kosong (tidak ada - atau +)"
    new = _apply_hunks(old, removals, additions)
    if new is None:
        return f"ERROR: konteks tidak cocok di {path} — baca file dulu (read_file) lalu patch ulang"
    target.write_text("\n".join(new) + "\n")
    return f"OK: {path} di-patch ({len(removals)} hapus, {len(additions)} tambah)"

def _apply_hunks(old: list[str], removals: list[str], additions: list[str]) -> list[str] | None:
    """Cari blok kontigu '-...' dan ganti dengan '+...' (strategi: match dari baris pertama
    yang cocok berurutan). Tanpa removals, sisipkan additions setelah konteks terdekat."""
    # implementasi penuh: cari index old[i] == removals[0] lalu cek run; fallback
    # difflib.SequenceMatcher.get_opcodes untuk patch yang tidak lurus.
    sm = difflib.SequenceMatcher(None, old, removals + additions, autojunk=False)
    # --- implementasi pragmatis: gunakan opcodes untuk ganti run removal dengan addition ---
    return _apply_via_opcodes(old, removals, additions)

def _apply_via_opcodes(old, removals, additions):
    sm = difflib.SequenceMatcher(None, old, removals, autojunk=False)
    new, i = [], 0
    for tag, i1, i2, j1, j2 in sm.get_opcodes():
        if tag == "equal":
            new.extend(old[i1:i2]); i = i2
        elif tag in ("delete", "replace"):
            if i1 != i2:                    # hapus baris lama
                new.extend(additions)       # ganti dengan tambahan
            i = i2
    return new
```
*Catatan implementer: versi di atas adalah kerangka; task ini mengharuskan kamu menulis `_apply_hunks` yang benar dengan 3 kasus uji: (a) replace baris, (b) sisipkan baris baru, (c) patch gagal → pesan error. Selesaikan sampai semua test hijau — ini tool paling kritis.*

from dhybrid.llm.base import ChatMessage

MECHANICAL_HINTS = [
    r"\b(grep|find|search|list|show|cat|head|tail|status)\b",
    r"\b(run|execute|test|pytest)\b",
    r"\b(format|rename|move|copy|delete)\b",

    low = prompt.lower()

    if any(re.search(p, low) for p in MECHANICAL_HINTS):
        return "small"
    # default: prompt pendek (< 200 char) dan tanpa kata kunci → small
    return "small" if len(prompt) < 200 else "big"

from dhybrid.efficiency.cache import PromptCache

class HybridRouter:
    """Pilih client: model kecil untuk task mekanis, model besar untuk penalaran.
    Klasifikasi di-cache (PromptCache) supaya tidak bayar token classifier."""

    def __init__(self, big_client, small_client, cache: PromptCache | None = None):
        self.big = big_client
        self.small = small_client
        self.cache = cache
        self.stats = {"small": 0, "big": 0}

    def route(self, prompt: str):
        cls = "small"
        if self.cache:
            hit = self.cache.get("classifier", [ChatMessage(role="user", content=prompt)])
            cls = hit if hit else None
        if cls is None:
            cls = classify_task(prompt)
            if self.cache:
                self.cache.set("classifier", [ChatMessage(role="user", content=prompt)], cls)
        self.stats[cls] += 1
        return self.small if cls == "small" else self.big
```

def repl_loop(agent_factory, welcome: str = "dhybrid-agent — ketik /help") -> int:
    print(style(welcome, "1;36"))
    while True:
        try:
            prompt = input(style("dhybrid> ", "32")).strip()
        except (EOFError, KeyboardInterrupt):
            print("\nbye")
            return 0
        if not prompt:
            continue
        if prompt.startswith("/"):
            if handle_command(prompt, agent_factory):   # True = quit
                return 0
            continue
        # jalankan agent; stream delta langsung dicetak
        result = agent_factory().run(prompt)
        print()
```

### Phase 9 — Persistence & Memory (own-your-data ala OpenClaw)

#### Task 9.1: SQLite session store

**Files:**
- Create: `src/dhybrid/session/store.py`
- Test: `tests/unit/test_store.py`

**Step 1: `src/dhybrid/session/store.py`**
```python
from __future__ import annotations
import json
import sqlite3
import uuid
from datetime import datetime, timezone
from pathlib import Path

SCHEMA = """
CREATE TABLE IF NOT EXISTS sessions (
    id TEXT PRIMARY KEY, created TEXT, title TEXT, summary TEXT);
CREATE TABLE IF NOT EXISTS messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT, session_id TEXT, role TEXT,
    content TEXT, tool_calls TEXT, created TEXT,
    FOREIGN KEY(session_id) REFERENCES sessions(id));
CREATE TABLE IF NOT EXISTS usage (
    id INTEGER PRIMARY KEY AUTOINCREMENT, session_id TEXT, model TEXT,
    prompt_tokens INTEGER, completion_tokens INTEGER, cached_tokens INTEGER,
    cost REAL, created TEXT);
"""

class SessionStore:
    def __init__(self, db_path: Path | None = None):
        self.db_path = Path(db_path or Path.home() / ".dhybrid" / "sessions.sqlite")
        self.db_path.parent.mkdir(parents=True, exist_ok=True)
        self.conn = sqlite3.connect(self.db_path)
        self.conn.executescript(SCHEMA)

    def new_session(self, title: str = "untitled") -> str:
        sid = uuid.uuid4().hex[:12]
        self.conn.execute("INSERT INTO sessions VALUES (?,?,?,?)",
                          (sid, datetime.now(timezone.utc).isoformat(), title, ""))
        self.conn.commit()
        return sid

    def append_message(self, sid: str, role: str, content: str, tool_calls=None) -> None:
        self.conn.execute("INSERT INTO messages (session_id, role, content, tool_calls, created) VALUES (?,?,?,?,?)",
                          (sid, role, content, json.dumps(tool_calls) if tool_calls else None,
                           datetime.now(timezone.utc).isoformat()))
        self.conn.commit()

    def record_usage(self, sid: str, model: str, prompt: int, completion: int, cached: int, cost: float) -> None:
        self.conn.execute("INSERT INTO usage VALUES (?,?,?,?,?,?,?)",
                          (None, sid, model, prompt, completion, cached, cost,
                           datetime.now(timezone.utc).isoformat()))
        self.conn.commit()

    def sessions(self, limit: int = 20) -> list[dict]:
        rows = self.conn.execute("SELECT id, created, title FROM sessions ORDER BY created DESC LIMIT ?", (limit,)).fetchall()
        return [{"id": r[0], "created": r[1], "title": r[2]} for r in rows]
```

## 7. Metrik Hemat Token (Definisi)

| Metrik | Definisi | Target |
|---|---|---|
| Token/sesi | prompt+completion (dari usage API) | task kecil ≤ 40k |
| Cache-hit ratio | `cached / (cached+uncached prompt)` | ≥ 50% |
| Kompaksi/sesi | jumlah `apply_compaction` | 0-2 untuk task kecil |
| Biaya/sesi | token × harga provider | turun ≥ 50% vs mode off |
| Routing split | `small:big` dari `router.stats` | ≥ 60% small |

## 8. Risiko, Tradeoff, Open Questions

- **Risiko kompaksi:** ringkasan bisa kehilangan detail → mitigasi: keep_recent cukup besar (8), summary dipaksa berisi "belum selesai".
- **Risiko parser patch:** diff custom rawan konflik → mitigasi: error message memerintah baca ulang file; fallback ke `difflib` opcodes; test 3 kasus.
- **Tradeoff provider native tool-calling vs JSON block:** native lebih hemat token tapi kurang portabel; solusi: dukung dua-duanya (parse native bila ada, fallback `parse_tool_call`).
- **Keamanan `shell=True`:** mitigasi allowlist + konfirmasi command berbahaya + mode `--yes` menolak.
- **Keputusan user (sudah dikonfirmasi):**
  1. **Provider: cloud-only** — user punya banyak API key. Preset lengkap: OpenAI, Anthropic, OpenRouter, Gemini, Groq, DeepSeek. **TANPA Ollama lokal** (sudah dihapus dari plan).
  2. **Bahasa: Python 3.12** — pilihan terbaik untuk kasus ini (ekosistem LLM paling kaya, stdlib lengkap utk CLI/agent/sqlite, cepat dikembangkan).
  3. **Platform: Linux only** — `pathlib`/`subprocess`/`sqlite3` semua cross-platform, tapi target & pengujian hanya Linux.
- **Saran terbaik (rekomendasi tambahan):**
  - **Default model utama: `anthropic-big`** (Claude Sonnet — secara konsisten terbaik untuk coding). Default model kecil/cepat: `openai-fast` (gpt-4o-mini — murah, cepat, akurat utk tugas mekanis).
  - **OpenRouter = satu key untuk semua model** — paling fleksibel untuk eksperimen model tanpa buat key baru.
  - **Gemini Flash sebagai model kecil alternatif** — termurah di kelasnya, context window sangat besar (1M) → bagus untuk file besar.
  - Pakai `uv` daripada pip (Task 1.3) — instalasi & venv jauh lebih cepat.
  - Tambah `ruff` utk linting sejak awal — mencegah technical debt.
  - `.env` loader manual 12 baris — tidak perlu dependensi `python-dotenv`.
  - V0.2 roadmap (setelah MVP stabil): MCP tools, browser tool, gateway multi-channel ala OpenClaw, dukungan model lokal bila suatu saat mau.
